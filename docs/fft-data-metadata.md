# FFT 데이터 메타데이터

FFT CSV의 각 행은 하나의 FFT 측정 기록이며, `ResultData`와 함께 다음 메타데이터를 사용합니다.

## 필드

| 필드 | 의미 | 비고 |
| --- | --- | --- |
| `MeasureDate` | 채취일시 | FFT 측정 기록의 일시 |
| `ExtractionType` | 채취종류 | 정기 또는 경보에 의해 채취된 종류 |
| `DiagMode` | 진단모드 | 진단 대상 부품 종류 |
| `MeasureMode` | 측정모드 | FFT 진폭 데이터의 측정 종류 |
| `MeasureFreq` | 분해능 | FFT 그래프의 주파수 범위 |

일부 기존 CSV는 `DiagMode`가 `DaiagMode`로 기록되어 있습니다. 대시보드는 두 헤더를 모두 읽고 API에서는 `diagMode`로 통일합니다.

## 코드값

### ExtractionType

| 값 | 의미 |
| --- | --- |
| `2` | 정기 |
| `3` | 주의경보 |
| `4` | 위험경보 |

### DiagMode

| 값 | 의미 |
| --- | --- |
| `0` | 없음 |
| `1` | 기구부 |
| `2` | 구름베어링 |
| `11` | 기어2 |
| `12` | 기어1 |

### MeasureMode

| 값 | 의미 | 진폭 단위 |
| --- | --- | --- |
| `0` | 가속도ALL | `g` |
| `2` | 가속도ENV | `g` |
| `3` | 속도 | `mm/s` |

### MeasureFreq

| 값 | 주파수 범위 |
| --- | --- |
| `5` | 500 Hz |
| `6` | 1 kHz |
| `9` | 10 kHz |
| `10` | 20 kHz |

등록되지 않은 코드는 원본 값을 유지하고 화면에는 `알 수 없음 (코드)`으로 표시합니다. `MeasureFreq`가 등록되지 않은 기록은 주파수 대신 FFT bin을 X축으로 사용합니다.
