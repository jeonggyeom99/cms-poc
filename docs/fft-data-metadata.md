# FFT 데이터 메타데이터

FFT CSV의 각 행은 하나의 FFT 측정 기록이며, `ResultData`와 함께 다음 메타데이터를 사용합니다.

## 필드

| 필드 | 의미 | 비고 |
| --- | --- | --- |
| `MeasureDate` | 채취일시 | FFT 측정 기록의 일시 |
| `ExtractionType` | 채취종류 | 정기 또는 경보에 의해 채취된 종류 |
| `DiagMode` | 진단모드 | 진단 대상 부품 종류 |
| `MeasureMode` | 측정모드 | FFT 진폭 데이터의 측정 종류 |
| `MeasureFreq` | 분해능 | FFT 그래프의 주파수 범위 |

일부 기존 CSV는 `DiagMode`가 `DaiagMode`로 기록되어 있습니다. 대시보드는 두 헤더를 모두 읽고 API에서는 `diagMode`로 통일합니다.

## 코드값

### ExtractionType

| 값 | 의미 |
| --- | --- |
| `2` | 정기 |
| `3` | 주의경보 |
| `4` | 위험경보 |

### DiagMode

| 값 | 의미 |
| --- | --- |
| `0` | 없음 |
| `1` | 기구부 |
| `2` | 구름베어링 |
| `11` | 기어2 |
| `12` | 기어1 |

### MeasureMode

| 값 | 의미 | 진폭 단위 |
| --- | --- | --- |
| `0` | 가속도ALL | `g` |
| `2` | 가속도ENV | `g` |
| `3` | 속도 | `mm/s` |

### MeasureFreq

| 값 | 주파수 범위 |
| --- | --- |
| `5` | 500 Hz |
| `6` | 1 kHz |
| `9` | 10 kHz |
| `10` | 20 kHz |

등록되지 않은 코드는 원본 값을 유지하고 화면에는 `알 수 없음 (코드)`으로 표시합니다. `MeasureFreq`가 등록되지 않은 기록은 주파수 대신 FFT bin을 X축으로 사용합니다.

## 가속도 FFT 베어링 분석

가속도 ALL(`0`)과 가속도 ENV(`2`) 기록은 설비 메타데이터의 `maker`, `bearing`, `rpm`과
`data/0. Bearing_Fault_Frequency_Master_File.txt`를 사용해 베어링 결함 주파수를 계산합니다.

```text
회전주파수 = RPM / 60
결함 1X = 회전주파수 × 결함계수(BPFO/BPFI/BSF/FTF)
결함 2X, 3X = 결함 1X × 2, 3
```

각 목표 주파수의 ±5 Hz에서 최대 Peak를 찾습니다. 1X/2X/3X 중 하나라도 `0.5 g` 이상이면
해당 결함 유형을 이상 후보로 분류합니다. 이상 후보가 없으면 BPFO를 기본 선택하고, 후보가
여러 개이면 참조 가중 점수(1X + 2X/2 + 3X/3 및 사이드밴드 점수), 최대 Peak, 고정 순서
BPFO/BPFI/BSF/FTF로 선택합니다.

마스터에 제조사·형번이 없거나 중복 계수가 충돌하면 분석하지 않고 사유를 표시합니다.
