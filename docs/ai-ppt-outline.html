01

입력 데이터

03

검증 → 결과 활용

구조와 측정 근거를 검사한 뒤 UI와 진단 보고서에 연결합니다.

분석 근거 준비와 이력 압축

전체 이력을 요약하되,
관측 근거를 보존합니다.

최근 90일 Trend + 보유한 전체 FFT 이력

01

Trend · 90일

월별 평균·표본 수·실제 관측 기간과 이전 월 대비 변화량을 제공합니다.

02

FFT · 조건별 비교

모드·단위·측정점·RPM·주파수 범위·분해능별로 그룹을 분리합니다. 월별 최초·최신·최소·최대는 실제 관측값입니다.

03

대표 기록 · 그룹당 최대 6개

최초·최신·최초 이상·주요 진폭 최대 기록에서 중복을 제거합니다. 관련 이력과 해석 제한도 전달하며 원본 FFT 배열은 제외합니다.

설비 단위 종합 분석

한 기록의 소견을 넘어,
설비의 변화를 설명합니다.

FFT 선택 변경과 설비 종합 분석을 분리한 사용 흐름

01

관찰과 비교 근거

Trend·FFT 요약, 상세 소견, 실제 비교 기간과 대표 FFT 기록을 표시합니다.

02

원인 후보와 반대 근거

가능한 원인과 이를 지지하는 근거, 진단 제한을 함께 제시합니다.

03

우선 점검

관찰 결과를 점검 조치로 연결합니다. FFT 선택 변경 시 재분석하지 않으며 “다시 분석”으로 갱신합니다.

도구 호출 기반 질의응답

질문에 맞는 데이터를
도구로 확인합니다.

질문 → 도구 선택 → 서버 조회 → 근거 기반 답변

01

채팅 조회 도구

get_trend · get_fft · get_bearing_fft · get_related_history

02

설비 종합 분석의 추가 조회

초기 근거가 충분하면 AI 요청 한 번으로 완료합니다. 필요 시 FFT·이력 근거를 최대 2단계·4개 호출로 조회합니다. 이력 페이지는 최대 50개입니다.

03

질문 예시

“이 설비의 8월 31일 FFT는 어떤 상태인가요?” 요청한 날짜를 조회하고 화면에서 선택한 다른 날짜 기록과 구분합니다.

응답 검증과 오류 대응

답변의 형식과 근거를
함께 확인합니다.

생성 → 구조 검사 → 근거 검사 → 보정 또는 오류 안내

01

구조와 근거 검사

JSON 필드, 수치·단위·기간·원인 주장·대표 기록을 전달된 근거와 대조합니다.

02

최대 두 번 보정

응답 잘림이나 검증 실패 시 같은 근거로 재생성합니다. 보정 중에는 도구를 추가 호출하지 않습니다.

03

제한과 운영 추적

1X 우세만으로 축정렬 불량을 단정하지 않습니다. 요청 ID와 실패 단계를 기록하고 설정·인증·시간 초과 오류를 안내합니다.

응답 시간 개선과 캐시 전략

필요한 조회를 줄이고,
같은 분석을 재사용합니다.

초기 근거 제공 + 파일 캐시 + 동시 요청 공유

01

최초 분석

Trend·FFT·관련 이력을 첫 요청에 제공해 반복 조회를 줄입니다.

02

기본 24시간 캐시

동일 입력·모델·분석 버전의 결과를 파일로 보관하며 서버 재시작 후에도 재사용합니다.

03

갱신과 요청 공유

입력·모델·분석 버전 변경 시 새로 분석합니다. 수동 재분석은 캐시를 우회하고 동일한 진행 중 요청은 공유합니다.

보고 업무에 연결합니다.

진단 문구와 화면 그래프를 활용한 산출물

01

진단결과 PPTX

한 장짜리 설비 진단 보고서를 만듭니다. 별도 AI 검증 단계가 렌더링 이미지와 도형·표 좌표를 확인합니다.

02

검증과 수정

최대 두 번 수정하며 진단 수치·조건·불확실성을 보존합니다. 검증 통과·경고·미완료 상태를 제공합니다.

03

이메일 초안

한국어 본문과 그래프를 미리보기·복사합니다. 실제 메일 전송은 제공하지 않습니다.

현재 한계와 다음 단계

현장 검증을 쌓으며,
운영 적용으로 확장합니다.

현재 범위와 향후 개선 제안을 구분합니다.

01

현재 한계

측정 조건·베어링 정보 부족, 큰 초기 입력량, 모델 응답 변동성이 있습니다. 남은 수명과 MTBF는 예측하지 않습니다.

02

개선 후보

입력 압축, 평가 데이터 확장, 담당자 승인·피드백, 외부 운영 시스템 연계를 제안합니다.

03

현장 적용의 기준

근거 검사 통과와 실제 진단 정확도는 별도입니다. 운전 조건과 현장 점검 결과를 포함해 최종 판단합니다.
